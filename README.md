# 换气接力 · 合唱排练换气规划

一个帮助合唱团安排「换气接力」的 Web 工具：为每位歌手在统一秒轴上规划换气区间，系统按半开区间 `[start, end)` 实时计算各声部同时在唱的人数，把低于该声部最低发声人数要求的时段合并并标红；还可以对任意换气段做 ±N 秒整数穷举寻优，一键找到让全曲未达标时间最短的新位置。此外支持「持续发声疲劳」检查：为每位歌手设置最长连续发声秒数与有效恢复换气秒数后，超限时段会在歌手轨道上独立标出。另有「临时缺席预演」：为多位歌手分别添加按秒计的临时缺席，只在当前页面重算覆盖并标出由缺席新增的未达标时段，不改工程。

技术栈：React 18 + TypeScript + Vite，纯前端，数据保存在浏览器 localStorage。

## 一键启动（Docker Compose）

```bash
docker compose up --build
```

然后访问 **http://localhost:8080**

也可以只用 Docker：

```bash
docker build -t breath-relay .
docker run --rm -p 8080:80 breath-relay
```

## 本地开发

```bash
npm install
npm run dev        # http://localhost:5173
```

构建产物预览：

```bash
npm run build
npm run preview
```

## 功能说明

- **声部与歌手管理**：左侧栏添加/删除声部与歌手，设置每个声部的「最低发声人数」与全曲时长。
- **换气区间编辑**：在中间时间轴上
  - 双击歌手轨道空白处：新增换气段（默认 2 秒）；
  - 拖动换气段：整体移动（自动避开同歌手其它区间、不越界）；
  - 拖动换气段两端：调整时长（最短 0.5 秒）；
  - 点击选中，Delete / Backspace 删除。
- **实时覆盖计算**：按半开区间扫描线算法统计每个声部每时刻的在唱人数；人数不足的时段自动合并，在声部覆盖行上以红色条纹标出（悬停可见最少人数与缺口）。
- **换气段寻优**：选中换气段后，在 ±N 秒（整数）范围内穷举所有「保持时长不变、不与该歌手其它区间重叠、不越界」的位置，依次最小化：
  1. 全曲未达标总秒数；
  2. 位移量 |Δt|；
  3. 平局取更早时刻。
- **修复前后预览**：寻优结果以虚线框预览新位置、原位置半透明显示，覆盖行与未达标统计实时切换为「修复后」视图；候选列表可切换预览不同位移，确认后一键应用。
- **声部接力排程（整组回溯搜索）**：
  - 在底部面板选择声部、起止拍位（小节:拍，半开 `[起, 止)`）与每人换气拍数；
  - 系统在该拍域内按**整拍枚举**候选（**跨变速点**时先在拍域枚举、再经节拍图换算为秒），为声部**每位歌手各安排一段新换气**，用回溯搜索（MRV）同时保证：
    1. 区间不越出拍域窗口（也不越出全曲）；
    2. 不与该歌手已有换气重叠（半开相邻允许）；
    3. 窗口内任意时刻发声人数不低于声部最低发声人数门槛；
  - 搜索结果以**整组幽灵块**（虚线块 + 琥珀色拍域窗口）预览，覆盖行实时按「整组写入后」计算；**确认后一次写入**（每人追加一段），**取消不改工程**；
  - 无解时区分两类原因：**「歌手无可用拍位」**（某些歌手在拍域内无满足越窗/重叠约束的拍位，列出歌手名）与**「覆盖门槛冲突」**（人人有位但无法同时满足门槛，或拍域内已有换气已超标）。
- **可编辑节拍图（小节/拍 ↔ 秒）**：
  - 在左侧设置拍号（如 4/4）、起始 BPM，并在任意小节首拍插入变速点；变速点始终按拍位排序、同一拍位不重复；
  - 基于分段恒速规则做「小节/拍 ↔ 秒」双向换算，时间轴标尺可在**秒标尺**与**节拍标尺**（小节号 + 变速点 ♩=BPM 标记 + 小节线）间切换；
  - 勾选「按拍吸附」后，双击新增或拖拽换气段都会落到整拍，**跨变速点**时先换算到拍域再取整，仍落到正确拍位；
  - 编辑节拍图**不会移动已有换气段的实际秒位置**，只重新显示其对应拍位（换气段提示与寻优面板同时给出秒和「小节:拍」）；
  - 节拍图随工程一起导入 / 导出 JSON、自动保存到 localStorage；**旧工程缺少该字段时按 4/4、120 BPM 处理**。
- **持续发声疲劳检查**：在左侧歌手名下设置「连续≤ N 秒 / 恢复≥ M 秒」（任一为 0 即停用；新歌手与旧工程默认 0/0 停用）。
  - 扫描全曲时，仅时长达到恢复阈值的换气会清零累计连续发声；较短的换气只暂停累计、不清零；
  - 累计连续发声超过上限后，从精确越界时刻起持续标记，直到下一次有效恢复开始（曲终仍未恢复则标记到全曲结束），边界一律按半开区间 `[start, end)` 处理；
  - 超限时段在歌手轨道上显示独立的橙色警示层（底层色带 + 顶部警示条，悬停可见峰值连续发声与上限），歌手名旁与顶部工具条同步显示警示计数；
  - 侧栏「🔥 疲劳警示汇总」按开始时间升序列出全部超限时段，点击条目即把时间轴滚动到对应歌手与时刻；
  - 拖拽、缩放、寻优与接力预览期间，警示基于预览工程实时重算，取消预览即还原；
  - 设置随工程导出 / 导入 JSON、自动保存到 localStorage，并随排练快照一起冻结 / 恢复；导入旧工程或旧快照时自动补 0/0（停用），负数或非有限值（NaN / Infinity）一律按 0 处理，不会进入状态。
- **示例数据与本地保存**：首次打开自动载入示例工程；所有修改自动保存到浏览器 localStorage，刷新不丢失；支持导出 / 导入 JSON 工程文件。
- **临时缺席预演（只影响当前页面）**：
  - 在底部「🚪 临时缺席预演」面板为**多名歌手分别添加 / 移除以秒计的缺席区间**（半开 `[start, end)`，可与既有换气重叠，输入会裁剪到全曲范围）；
  - 计算前先把**同一歌手的缺席与既有换气按半开区间合并去重**（重叠 / 相接处并为一段），因此任一时刻同一位歌手至多扣一人，不会因重叠被重复扣人；再按声部沿用现有扫描线覆盖算法重算；
  - 与原工程做半开集合差，**仅在时间轴标出由缺席新增的未达标时段**（紫色斜纹），原本就未达标的时段降为暗色；顶部工具条与面板同时显示**各声部新增未达标秒数**与合计；
  - 缺席区间在歌手轨道上显示为紫色虚线块；**不写入工程、不改动换气段、不持久化**；切换 / 导入工程、载入示例、恢复快照或编辑工程（含节拍图）时自动清空，面板「全部移除并退出预演」或横幅「退出预演」即恢复原覆盖；
  - 预演与单段寻优 / 整组接力预览互斥（缺席不是换气段，预演期间疲劳警示仍基于原工程）。
- **排练分钟预算分配（只影响当前页面）**：
  - 在底部「⏱ 排练分钟预算分配」面板输入本次排练的**总分钟数**与每声部的**最少 / 最多分钟数**，系统按**当前工程各声部的未达标总秒数**把整数分钟预算分配到每个声部；
  - 分配规则：先给每个声部补足最少量；余量在**未封顶**声部间按缺口秒数比例分配，份额触及上限的声部封顶退出，其余声部带着剩余预算**重新按比例分配**（注水迭代）；当前未封顶声部的缺口秒数全为零时在它们之间**等权分配**；
  - 每轮按最大余数法取整：先各取 floor，不足整分钟的**尾差按小数余量降序**补 1，小数余量相同再按**声部当前顺序**（左侧声部顺序）补足，最终分钟数**恰好用完**预算并逐声部展示分得分钟数与作为依据的未达标秒数（封顶声部标注「已封顶」）；
  - 输入校验：总分钟数与每个界限都必须是**非负整数**，每声部最少量不得大于最多量，预算必须落在「最少量合计」与「最多量合计」之间；任一不满足时面板只说明原因、**不显示旧方案**；
  - 工程改动后（增删声部 / 歌手、编辑换气等）结果**以当前覆盖重新计算**；方案**不写入工程、不持久化、不导出**，刷新后输入恢复默认，也不影响启动与现有数据。
- **排练快照**：在左侧「📸 排练快照」面板为当前工程保存**带名称的快照**，保存时**冻结声部、歌手及全部换气区间**（深拷贝，之后改动不影响快照；节拍图 / 曲名 / 全曲时长不在冻结范围内）。
  - 展开任意快照即按**歌手 ID**（歌手改名不影响对齐）对比它与当前工程的换气区间，依据半开区间 `[start, end)` 计算**新增、删除、移动（起点变化）与时长变化**，差异**按时间升序**展示（同时刻按歌手名排序），并汇总声部 / 歌手的增删；
  - 点击「恢复」后需在 4 秒内**二次确认**才会写入：用快照中的声部、歌手与换气区间整体替换当前工程；恢复后自动**清除当前选中段与寻优 / 接力预览**，**节拍图保持现状、不被快照覆盖**（曲名与全曲时长同样保持现状）；
  - 快照保存在浏览器独立的 localStorage 键中，与当前工程互不影响，可随时删除。

## 目录结构

```
src/
  lib/
    coverage.ts     # 半开区间扫描线：人数不足时段的合并与统计
    budget.ts       # 排练分钟预算分配：按各声部未达标秒数注水比例 + 封顶重分 + 最大余数法尾差
    absence.ts      # 临时缺席预演：同歌手换气/缺席半开合并去重、叠加工程、新增未达标集合差
    fatigue.ts      # 持续发声疲劳：越界标记扫描、有效恢复阈值、侧栏汇总排序、设置清洗
    optimize.ts     # ±N 秒整数穷举寻优（保持时长、避免重叠、三级目标排序）
    relay.ts        # 声部接力排程：整拍枚举 + 回溯搜索（越窗/重叠/门槛约束、两类无解、整组写入）
    constraints.ts  # 拖动/缩放的边界与重叠约束、按拍放置新换气段
    tempo.ts        # 节拍图：分段恒速的小节/拍 ↔ 秒换算、吸附、标尺刻度
    snapshot.ts     # 排练快照：冻结/恢复（保留节拍图）、按歌手 ID 的半开区间差异、清洗与持久化
    sample.ts       # 示例工程
    storage.ts      # localStorage 读写与数据校验（旧工程补默认节拍图与停用疲劳设置）
  components/
    Timeline.tsx        # 秒/拍双标尺、声部覆盖行、歌手行（疲劳警示层）、按拍吸附
    BreathBlock.tsx     # 可拖动/缩放的换气块
    Sidebar.tsx         # 声部与歌手管理、节拍图编辑、排练快照入口
    SnapshotPanel.tsx   # 快照保存/删除、差异展开（按时间排序）、二次确认恢复
    OptimizerPanel.tsx  # 寻优与前后差异预览
    RelayPanel.tsx      # 声部接力排程表单、搜索、两类无解提示与整组预览/写入
    AbsencePanel.tsx    # 临时缺席预演：多名歌手按秒缺席的添加/移除与各声部新增未达标统计
    BudgetPanel.tsx     # 排练分钟预算分配：总量/每声部上下限输入、校验提示、逐声部结果与缺口秒数
  App.tsx
```
